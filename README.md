# Data Science Projects

This repository contains basic, hands-on data science experiments for learning, exploring datasets, and demonstrating methods through notebooks.
## Tabular Data

- [Diabetes 130-US Hospitals](tabular_data/diabetes_hospital.ipynb) — **Tabular data classification:** predicts whether a hospital encounter is followed by a readmission within 30 days, comparing CatBoost and TabPFN on the UCI Diabetes 130-US Hospitals dataset.
- [Bike Sharing](tabular_data/bike_sharing.ipynb) — **Time-series prediction:** forecasts hourly bike rental demand from Capital Bikeshare data, comparing LightGBM and TabPFN with a previous-week baseline.
