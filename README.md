# Data Science Projects

These notebooks explore practical data science problems through classification, customer segmentation, and time-series forecasting. Each uses data exploration and modeling as a hands-on example for learning and experimentation.

## Tabular Data

- [Diabetes 130-US Hospitals](tabular_data/diabetes_hospital.ipynb) — Models for predicting 30-day hospital readmission with CatBoost, TabPFN, and AutoGluon Tabular.
- [Bike Sharing](tabular_data/bike_sharing.ipynb) — Models for forecasting hourly bike rentals with LightGBM, TabPFN, and AutoGluon Time Series.
- [Online Retail II Customer Segmentation](tabular_data/retail_segmentation.ipynb) — Groups customers by recency, purchase frequency, and spend using KMeans, GMM, and HDBSCAN.
